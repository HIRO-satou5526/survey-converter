# 土木・測量 座標・標高変換PWA

iPhone、iPad、Android、Windows PCで利用できる、土木・測量現場向けの座標・標高変換PWAです。

## インストール方法

1. このフォルダの内容をGitHub Pagesへアップロードします。
2. `index.html` が公開URLのトップで開けるようにします。
3. ブラウザで公開URLへアクセスします。

ローカル確認は任意の静的サーバーで実行します。

```bash
python -m http.server 4173
```

## iPhoneホーム画面追加方法

1. Safariで公開URLを開きます。
2. 共有ボタンを押します。
3. 「ホーム画面に追加」を選択します。
4. 名前を確認して「追加」を押します。

## 利用方法

1. 「変換」タブを開きます。
2. `XY → 緯度経度` または `緯度経度 → XY` を選択します。
3. 平面直角座標系（第1系〜第19系）を選択します。
4. 高さ入力方式を選び、高さを入力します。
5. 「変換」を押します。

出力は常に以下です。

- 緯度
- 経度
- X座標
- Y座標
- 楕円体高
- ジオイド高2011
- ジオイド高2024
- 標高（JGD2011）
- 標高（JGD2024）

## CSV利用方法

「CSV」タブで入力形式を選択し、1行1点で入力します。

対応形式:

- `X,Y,標高(JGD2011)`
- `X,Y,標高(JGD2024)`
- `X,Y,楕円体高`
- `緯度,経度,標高(JGD2011)`
- `緯度,経度,標高(JGD2024)`
- `緯度,経度,楕円体高`

変換後、「CSV保存」で結果を保存できます。

## JGD2011とJGD2024の違い

JGD2011は東北地方太平洋沖地震後の測地成果を反映した日本の測地基準です。JGD2024は新しい標高体系やジオイド2024の運用に合わせて扱う測地成果として選択肢を用意しています。水平座標の投影計算はGRS80楕円体を用います。

## ジオイド2011とジオイド2024の違い

ジオイド2011は従来の標高計算で使われてきたジオイドモデルです。ジオイド2024は2025年4月以降の新しい標高体系に対応するジオイドモデルです。

高さ計算は以下です。

- 楕円体高 = 標高 + ジオイド高
- 標高 = 楕円体高 - ジオイド高

## オフライン利用

PWA本体はService Workerでキャッシュされ、オフライン起動できます。

ジオイド高の取得優先順位:

1. アプリ内格子データ（同梱時）
2. LocalStorageに保存済みの取得キャッシュ
3. 国土地理院公開サービス


## ジオイド高取得エラーの原因と解決

GitHub Pagesは静的サイトのため、ブラウザ内のJavaScriptから国土地理院のジオイド高計算APIを直接 `fetch()` すると、CORS制限によりレスポンスを読めない場合があります。国土地理院API自体は値を返しますが、ブラウザが別ドメインの読み取りを止めるためです。

解決方法は中継APIを使うことです。このフォルダにはCloudflare Workers用の `geoid-worker.js` を同梱しています。

### Cloudflare Workersでの設定

1. Cloudflare Workersで新しいWorkerを作成します。
2. `geoid-worker.js` の内容を貼り付けてデプロイします。
3. 発行されたURLを控えます。例: `https://survey-geoid.example.workers.dev`
4. `config.js` を開き、以下のように設定します。

```js
window.SURVEY_CONFIG = {
  geoidProxy: "https://survey-geoid.example.workers.dev"
};
```

これでGitHub Pages上のPWAから、Worker経由でジオイド2011/2024を取得できます。

### ローカル確認

PC上で確認する場合は、同梱の `server.js` を使えます。

```bash
node server.js
```

その場合は `config.js` を一時的に以下へ変更します。

```js
window.SURVEY_CONFIG = {
  geoidProxy: "./api/geoid"
};
```
## 制限事項

GitHub Pagesは静的ホスティングのため、国土地理院APIがブラウザのCORS制限を受ける環境ではオンライン取得に失敗する場合があります。その場合は、ジオイド2011/2024の格子データをアプリに同梱するか、同一オリジンの中継APIを利用してください。

完全オフラインで高精度なジオイド高を計算するには、公式ジオイド格子データの同梱と補間処理が必要です。本実装はその差し替え口として `offlineGeoid()` を用意しています。
